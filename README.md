# 🧠 AI Resume Ranker & Career Coach

An **AI-powered web app** built with **Streamlit** that helps users analyze and improve their resumes using NLP and Gemini API.  
Get instant feedback, ATS score, skill match analysis, and personalized career advice.

---

## 🚀 Features
- 📄 Upload resume (PDF/DOCX)
- 🧠 AI resume feedback using Gemini or GPT
- 📊 ATS-style score generation
- 🧩 Skill match analyzer with trending roles
- 💬 Interactive Career Coach chat
- 📥 Downloadable AI-generated feedback report

---

## ⚙️ Tech Stack
- **Frontend:** Streamlit  
- **Backend:** Python  
- **AI Engine:** Gemini / GPT API  
- **Libraries:** PyPDF2, spaCy, requests, pandas, plotly
